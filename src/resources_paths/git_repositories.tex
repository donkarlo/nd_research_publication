   \section{GitHub Python repositories}
      \begin{itemize}
         \item \textbf{Sociomind:} Contains the code that integrates all components required to run the self-awareness framework. \seeherefooter{https://github.com/donkarlo/nd_sociomind_project}
         \item \textbf{Robotic AI:} Simulates a robot, from ROS bridges to its physical and software components, as a hierarchy of nodes. It provides a biological representation of a robot. \seeherefooter{https://github.com/donkarlo/nd_robotic_ai_project}
         \item \textbf{Math module:} Includes all object-oriented mathematical code required to handle operations such as linear algebra. \seeherefooter{https://github.com/donkarlo/nd_math_project}
         \item \textbf{Data science module:} Includes object-oriented implementations of data-science methods such as Transformers. \seeherefooter{https://github.com/donkarlo/nd_datascience_project}
         \item \textbf{Physics module:} Includes object-oriented implementations for motion, kinematics, and physical entities. For example, position and orientation objects are included in this repository. \seeherefooter{https://github.com/donkarlo/nd_physics_project}
         \item \textbf{Utility:} Includes functionality shared among the aforementioned modules. \seeherefooter{https://github.com/donkarlo/nd_utility_project}
         \item \textbf{LaTeX editor:} An editor for handling modular LaTeX repositories. \seeherefooter{https://github.com/donkarlo/nd_mind_mirror_project}
      \end{itemize}
