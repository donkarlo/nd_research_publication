   Neural encoding training resembles kinematic teaching \cite{ablett-2025-multimodal-and-force-matched-imitation-learning-with-a-see-through-visuotactile-sensor} in which an expert agent teaches another agent how it should coordinate its sensory observations with its motor capabilities.

   In this section, we discuss how to train the cognitive architecture described above such that, given a stimulus, both temporal and hierarchical patterns are learned.

   Sensory induction and perception are inspired by the human nervous system, in which each sensor plays the role of a sensory receptor. In diverging neural circuits derived from each sensor, the sensor readings are converted into probability particles (similar to neurotransmitter molecules that carry predetermined electrical loads in synaptic clefts) and distributed among desired states as IPSP or EPSP graded potentials. These potentials gradually increase or decrease the state-neuron potential until the state neuron spikes and creates an action potential.

   A state neuron represents a state in the state space and is treated analogously to a biological neuron. Similar to a neuron that receives neurotransmitters through ion gates and converts them into graded IPSP or EPSP potentials, it converts a sensor reading into positive or negative probability-like values that increase or decrease the state probability until the threshold is reached (similar to a neuronal spike when its voltage reaches -70 V). It then spikes and produces an action potential in two directions: one along the time axis at the same level and one along the abstraction axis.

   At the abstraction level, a pattern similar to converging neural circuits is followed to reach the highest level of abstraction.

   This language must allow a drone to detect something that it has not encountered in previous experiences as a novelty from which it can build new language components.

      \subsection{This research method}
         A method is needed that follows the following rules for training a variational autoencoder.

         \begin{itemize}
            \item The input consists of ROS YAML files containing multiple sensor readings. These provide multiple attribute--value, or structured-data, readings.
            \begin{itemize}
               \item For the data from each sensor, two virtual sensors are considered.
               \begin{itemize}
                  \item A sensor that measures the intensity of the signal
                  \item Another sensor that measures the rate of change of the previous sensor.
               \end{itemize}
            \end{itemize}
            \item Each of the aforementioned data points (nested attribute--value data) should be converted into parameters of a spike train of action potentials using a variational autoencoder. These parameters are listed in Table \ref{table_action_potential_parameters} for an action potential and in Table \ref{table_observation_neuron_spike_count_firing_rate} for a spike train.
            \item The ranges of the above parameters for each sensor must lie in non-conflicting intervals so that, by observing each parameter value, its originating sensor or change-rate sensor can be identified. This rule does not apply to spike-train parameters.
            \item The higher the sensor intensity, the higher the firing rate of the spike train. Thus, the intensity value depends on the density of spikes within a given time interval.
            \item The higher the rate of change of the sensor value, the higher the firing rate of the spike train.

         \end{itemize}

         Therefore, the experiment is divided into two phases. During the training phase, one robot (in this case, a UAV equipped with LiDAR and GPS) is instructed by a human agent to use its autopilot to reach a set of trajectory points and gather sensory data. From these data, temporal and abstraction models are built using the aforementioned method inspired by the human nervous system.

\section{GP training from sensory observation} \label{graded_potentials_calculations}
         In the presence of a sensory observation, the following process is used to assign a value and sign to graded potentials according to the Wasserstein distance between the observation and the clusters learned during the training phase.
         \begin{figure}[H]
            \centering
            \includegraphics[width=0.9\textwidth]{ipsp_epsp_determination.png}
         \end{figure}
         Let $\mathbf{x}$ denote the current point observation, and let the $k$th learned class $C_k$ contain $N_k$ observations,

         \[
         C_k
         =
         \left\{
         \mathbf{z}_{k,1},
         \mathbf{z}_{k,2},
         \ldots,
         \mathbf{z}_{k,N_k}
         \right\},
         \]

         where $\mathbf{z}_{k,j}$ denotes the $j$th observation belonging to class $C_k$.

         The empirical probability distribution \cite{wasserman-2006-all-of-nonparametric-statistics} \seeherefooter{/nd_math_learning_project/src/probability/distribution/non_parametric/empirical_probability_distribution.tex} representing class $C_k$ is

         \[
         \mu_k
         =
         \frac{1}{N_k}
         \sum_{j=1}^{N_k}
         \delta_{\mathbf{z}_{k,j}},
         \]

         where $\delta_{\mathbf{z}_{k,j}}$ denotes the Dirac measure concentrated at
         $\mathbf{z}_{k,j}$. Similarly, the point observation $\mathbf{x}$ is represented by the Dirac measure $\delta_{\mathbf{x}}$.

         \paragraph{Reason to use empirical distribution} The empirical distribution is used because it represents the complete set of observations in a class without assuming a specific parametric form for the cluster.

         The point-to-class $p$-Wasserstein distance is denoted by
         $d_k(\mathbf{x})$ and is defined as

         \[
         d_k(\mathbf{x})
         =
         W_p\!\left(
         \delta_{\mathbf{x}},
         \mu_k
         \right)
         =
         \left(
         \frac{1}{N_k}
         \sum_{j=1}^{N_k}
         \left\|
         \mathbf{x}
         -
         \mathbf{z}_{k,j}
         \right\|_2^p
         \right)^{1/p}.
         \]

         For the second-order Wasserstein distance used in this research,

         \[
         \boxed{
         d_k(\mathbf{x})
         =
         W_2\!\left(
         \delta_{\mathbf{x}},
         \mu_k
         \right)
         =
         \sqrt{
         \frac{1}{N_k}
         \sum_{j=1}^{N_k}
         \left\|
         \mathbf{x}
         -
         \mathbf{z}_{k,j}
         \right\|_2^2
         }
         }.
         \]

         Therefore, $d_k(\mathbf{x})$ represents the Wasserstein distance between the current point observation $\mathbf{x}$ and the empirical distribution of class $C_k$.

         In this particular point-to-empirical-distribution case, it is equal to the root mean squared Euclidean distance from $\mathbf{x}$ to all observations belonging to $C_k$.

         \cite{ester-1996-a-density-based-algorithm-for-discovering-clusters-in-large-spatial-databases-with-noise} introduced DBSCAN, a density-based
         clustering algorithm capable of discovering arbitrarily shaped clusters
         while identifying observations in low-density regions as noise.

         In this research, DBSCAN is responsible for clustering the spike-train parameters derived from state neurons.

         DBSCAN is used because of the following advantages.

         \begin{itemize}
            \item DBSCAN does not require the number of clusters to be specified in advance.
            \item It can discover clusters with arbitrary shapes.
            \item It can explicitly identify noise and outlier points.
            \item It is suitable for datasets in which clusters are separated by low-density regions.
            \item It can use different distance functions depending on the structure of the data.
         \end{itemize}

      \subsection{Motif discovery - GRU-auto-encoder based}
         For general information, see \seeherefooter{/nd_math_learning_project/src/statistics/sequence/timeseries/motif_discovery/motif_discovery.tex}
         Two well-known methods are introduced in \cite{guerrini-2025-time-series-motif-discovery-a-comprehensive-evaluation, linardi-2018-matrix-profile-x-valmod-scalable-discovery-of-variable-length-motifs-in-data-series}. For the autoencoder-based motif-discovery approach adapted in this research, see \seeherefooter{/nd_math_learning_project/src/statistics/sequence/timeseries/motif_discovery/gru_autoencoder_based/gru_autoencoder_based.tex} and \cite{bascol-2016-unsupervised-interpretable-pattern-discovery-in-time-series-using-autoencoders}.

         Motif discovery is performed independently at each representation level. In this research, a GRU autoencoder is used to map variable-length candidate subsequences to fixed-dimensional latent representations. Motifs are then formed by grouping recurrent candidates that are sufficiently close in this latent space.

         For a selected representation level $\ell$, let

         \[
         \mathbf{s}_{\ell}
         =
         \left(
         s_{\ell,1},
         s_{\ell,2},
         \ldots,
         s_{\ell,N_{\ell}^{\mathrm{mot}}}
         \right)
         \]

         denote the ordered spike sequence generated by state neurons belonging to that level.

         A variable-length candidate subsequence is

         \[
         \mathbf{s}_{\ell}[u:v]
         =
         \left(
         s_{\ell,u},
         \ldots,
         s_{\ell,v}
         \right),
         \qquad
         1 \leq u < v \leq N_{\ell}^{\mathrm{mot}}.
         \]

         Each candidate is encoded by the level-specific GRU encoder,

         \[
         \mathbf{g}_{\ell,u:v}
         =
         \mathcal{E}^{\mathrm{mot}}_{\eta_{\ell}}
         \left(
         \mathbf{s}_{\ell}[u:v]
         \right).
         \]

         The corresponding decoder $\mathcal{D}^{\mathrm{mot}}_{\xi_{\ell}}$ is trained together with the encoder to reconstruct the candidate subsequences. After training, recurrent latent representations are grouped around latent motif prototypes $\mathbf{c}_{\kappa,\ell}$.

         A candidate subsequence is assigned to motif $\kappa$ when

         \[
         \Delta^{\mathrm{mot}}_{\ell}
         \left(
         \mathbf{g}_{\ell,u:v},
         \mathbf{c}_{\kappa,\ell}
         \right)
         \leq
         \varepsilon^{\mathrm{mot}}_{\ell}.
         \]

         The representative subsequence associated with the $\kappa$th accepted recurrent group is denoted by $\mathbf{m}_{\kappa,\ell}$. The same procedure is applied independently for every selected representation level $\ell \in L$, without requiring information from either a lower or a higher representation level.

         \begin{algorithm}[H]
            \caption{GRU-autoencoder-based level-independent motif discovery}

            \begin{algorithmic}[1]
               \For{each selected representation level $\ell \in L$}
               \State Collect the spike sequence $\mathbf{s}_{\ell}$
               \State Generate variable-length candidate subsequences $\mathbf{s}_{\ell}[u:v]$
               \State Train $\mathcal{E}^{\mathrm{mot}}_{\eta_{\ell}}$ and $\mathcal{D}^{\mathrm{mot}}_{\xi_{\ell}}$ to reconstruct the candidate subsequences
               \For{each candidate $\mathbf{s}_{\ell}[u:v]$}
               \State $\mathbf{g}_{\ell,u:v} \gets \mathcal{E}^{\mathrm{mot}}_{\eta_{\ell}}\!\left(\mathbf{s}_{\ell}[u:v]\right)$
               \EndFor
               \State Initialize an empty set of motif groups and latent prototypes
               \For{each latent candidate $\mathbf{g}_{\ell,u:v}$}
               \If{no latent motif prototype exists}
               \State Create the first motif group and initialize its prototype with $\mathbf{g}_{\ell,u:v}$
               \Else
               \State Find the nearest latent motif prototype $\mathbf{c}_{\kappa,\ell}$ using $\Delta^{\mathrm{mot}}_{\ell}$
               \If{$\Delta^{\mathrm{mot}}_{\ell}(\mathbf{g}_{\ell,u:v},\mathbf{c}_{\kappa,\ell}) \leq \varepsilon^{\mathrm{mot}}_{\ell}$}
               \State Assign $\mathbf{s}_{\ell}[u:v]$ to motif group $\kappa$ and update $\mathbf{c}_{\kappa,\ell}$
               \Else
               \State Create a new motif group with $\mathbf{g}_{\ell,u:v}$ as its initial prototype
               \EndIf
               \EndIf
               \EndFor
               \State Discard groups that do not contain at least two non-overlapping occurrences
               \State For each remaining group, store the subsequence nearest to its prototype as $\mathbf{m}_{\kappa,\ell}$
               \EndFor
               \State \Return the motifs discovered independently at each representation level
            \end{algorithmic}
         \end{algorithm}

   \section{Transformers}
      Because different compositions of language segments form different meanings, LSTMs (and consequently RNNs) cannot capture all local dependencies. A multi-head-attention predictor is needed; Transformers provide this mechanism \cite{vaswani-2017-attention-is-all-you-need}.

      Its application here is to replace the constant-speed predictor.

      \begin{itemize}
         \item At the lowest level, each cell holds an AP wave represented by FMM.
         \item Training
         \begin{itemize}
            \item Deep learning with autocorrelation to find periods.
         \end{itemize}
         \item Sliding windows to train the Transformer.
         \item Period sampling with autocorrelation for training and validating the Transformer.
         \item Noise as uncertainty in the Transformer.

      \end{itemize}

      \subsection{Gaussian Transformer}
         For all details, see \seeherefooter{/nd_datascience_learning_project/src/machine_learning/model/architecture/neural_network/kind/deep_learning/kind/transformer/kind/uncertainty/uncertainty.tex}

         The model receives a past time-series window and predicts a future window with uncertainty.

         \[
         f_{\theta}:
         \mathbb{R}^{T_{\mathrm{in}} \times F_{\mathrm{in}}}
         \rightarrow
         \mathbb{R}^{T_{\mathrm{out}} \times 2F_{\mathrm{out}}}
         \]

         For each future time step and feature, it predicts two values:

         \[
         \hat{Y}_{\mathrm{params}}
         =
         [
         \mu,
         \log \sigma^2
         ]
         \]

         \[
         y_{b,t,j}
         \sim
         \mathcal{N}
         (
         \mu_{b,t,j},
         \sigma^2_{b,t,j}
         )
         \]

         \begin{itemize}
            \item \(\mu\): expected future value
            \item \(\sigma^2 = \exp(\log \sigma^2)\): predictive uncertainty
         \end{itemize}

         \subsubsection{Loss and uncertainty calculation}
            The model is trained with Gaussian negative log-likelihood:

            \[
            \mathcal{L}
            =
            \frac{1}{BT_{\mathrm{out}}}
            \sum_{b=1}^{B}
            \sum_{t=1}^{T_{\mathrm{out}}}
            \sum_{j=1}^{F_{\mathrm{out}}}
            \frac{1}{2}
            \left[
            \log \sigma^2_{b,t,j}
            +
            (y_{b,t,j}-\mu_{b,t,j})^2
            \exp
            (
            -\log \sigma^2_{b,t,j}
            )
            \right]
            \]

            Approximate 95\% prediction interval:

            \[
            y_{b,t,j}
            \in
            [
            \mu_{b,t,j}
            -
            1.96\sigma_{b,t,j},
            \mu_{b,t,j}
            +
            1.96\sigma_{b,t,j}
            ]
            \]

            \begin{itemize}
               \item Small variance means high confidence.
               \item Small variance means high confidence.
            \end{itemize}

   \section{Period detection with GRU-based latent autocorrelation and the Fast Fourier Transform\protect\footnotemark}\footnotetext{This part is used only for train--test splitting in experiments that investigate the effect of increasing or decreasing the number of periods on the framework's performance.}
      \seeherefooter{/nd_datascience_learning_project/src/signal_processing/auto_correlation/fast_fourier_transform.tex}

      For the implementation, see \seeherefooter{/repo/nd_datascience_project/src/nd_datascience/machine_learning/model/application/auto_correlation/sequence/period/neural/}

      The Fast Fourier Transform (FFT) is an autocorrelation method that efficiently converts a time-domain signal into its frequency components, allowing periodicity to be detected by identifying dominant frequencies corresponding to repeating patterns \cite{berberidis-2002-on-the-discovery-of-weak-periodicities-in-large-time-series}.

      A Gated Recurrent Unit (GRU) is a recurrent neural unit that uses reset and update gates to adaptively control how information is forgotten and retained across a sequence \cite{cho-2014-learning-phrase-representations-using-rnn-encoder-decoder-for-statistical-machine-translation}.

      The proposed period-discovery method first transforms the spike-train activity into a learned latent representation and then applies autocorrelation in the latent space. For each discrete interval, the observation-neuron firing rates are collected into

      \[
      \mathbf{q}_n
      =
      \operatorname{vec}_{i,d\in\{0,1\}}
      \left(
      r_{Z_i^{(d)}}([t_n,t_{n+1}])
      \right),
      \]

      where $r_{Z_i^{(d)}}([t_n,t_{n+1}])$ is the firing rate of observation neuron $Z_i^{(d)}$ during the corresponding interval.

      Overlapping windows of length $W$ are passed through a GRU autoencoder \cite{cho-2014-learning-phrase-representations-using-rnn-encoder-decoder-for-statistical-machine-translation}. The encoder produces a $K$-dimensional latent sequence

      \[
      \mathbf{h}_n
      =
      \mathcal{E}_{\phi}
      \left(
      \mathbf{q}_{n-W+1:n}
      \right),
      \]

      while the decoder $\mathcal{D}_{\psi}$ is trained to reconstruct the original window by minimizing

      \[
      (\phi^{*},\psi^{*})
      =
      \arg\min_{\phi,\psi}
      \sum_n
      \left\|
      \mathbf{q}_{n-W+1:n}
      -
      \mathcal{D}_{\psi}
      \left(
      \mathcal{E}_{\phi}
      \left(
      \mathbf{q}_{n-W+1:n}
      \right)
      \right)
      \right\|_2^2 .
      \]

      After training, overlapping latent representations are averaged to obtain one latent vector $\mathbf{h}_n$ for each time step. The multivariate latent autocorrelation at lag $\tau$ is then

      \[
      \rho_{\mathrm{GRU}}(\tau)
      =
      \frac{1}{n_{\max}-\tau}
      \sum_{k=1}^{K}
      \sum_{n=0}^{n_{\max}-\tau-1}
      h_{n,k}h_{n+\tau,k}.
      \]

      In the implementation, this autocorrelation is calculated efficiently using the Fast Fourier Transform,

      \[
      \rho_{\mathrm{GRU}}(\tau)
      =
      \frac{1}{n_{\max}-\tau}
      \sum_{k=1}^{K}
      \operatorname{IFFT}
      \left(
      \operatorname{FFT}(\mathbf{h}_{:,k})
      \overline{\operatorname{FFT}(\mathbf{h}_{:,k})}
      \right)_{\tau}.
      \]

      The estimated period is the first autocorrelation peak after a predefined minimum admissible lag $\tau_{\min}$,

      \[
      \hat{\tau}_{\mathrm{per}}
      =
      \min
      \left\{
      \tau \geq \tau_{\min}
      \mid
      \tau \text{ is a local maximum of }
      \rho_{\mathrm{GRU}}(\tau)
      \right\}.
      \]

      Thus, the GRU is not used to predict the period directly; it learns a latent representation in which repeated multivariate spike-train patterns can be detected by FFT-based autocorrelation.

      \begin{algorithm}[H]
         \caption{GRU-based latent autocorrelation for period discovery}
         \begin{algorithmic}[1]
            \State Construct firing-rate vectors $\mathbf{q}_n$ from the observation-neuron spike trains
            \State Form overlapping windows of length $W$
            \State Train a GRU autoencoder to reconstruct the input windows
            \State Encode all windows into latent sequences
            \State Average overlapping encodings to obtain one latent vector $\mathbf{h}_n$ per time step
            \State Compute multivariate autocorrelation of $\mathbf{h}_n$ using FFT
            \State Detect local maxima of $\rho_{\mathrm{GRU}}(\tau)$ for $\tau \geq \tau_{\min}$
            \State \Return the first detected peak as $\hat{\tau}_{\mathrm{per}}$
         \end{algorithmic}
      \end{algorithm}
