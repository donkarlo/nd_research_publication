    The architecture is formed of a set of neurons in the form of probabilistic graphical models
    
    
    \section{Architecture of a neuron}
        A neuron is formed of
        \begin{itemize}
            \item Soma/Cell body (evidence potential weighting center)
            \begin{itemize}
                \item Membrane potential
                \begin{itemize}
                    \item Action potential (Simulated with ``Frequency modulated ``)
                    \begin{itemize}
                        \item depolarization
                        \item repolarzation
                        \item refractory period
                    \end{itemize}
                    \item Wave form simulation wit ``Frequency-Modulated M\"obius (FMM)`` (These parameters must be trained in training phase)
                    \begin{itemize}
                        \item M
                        \item A
                        \item $\alpha$
                        \item \beta
                        \item \omega
                    \end{itemize}
                    \item Graded potential
                    \begin{itemize}
                        \item IPSP (to decrease the evidence potential)
                        \item EPSP (to increase the evidence potential)
                    \end{itemize}
                
                \end{itemize}
            
            \end{itemize}
            \item Axons and their terminals (output)
            \item Dendrites (inputs)
        \end{itemize}
    
    
    \section{Neuron types}
        \begin{itemize}
            \item Sensory modalities. each sensor modality is devided to two set of sensors similar to afferent SA/RA or sustained/tranient RGC in retina
            \begin{itemize}
                \item intensity sensor (measure the value of sensor, similar to RAA/SAA or SRG/TRG)
                \item intensity change sensor (measures how fast the sensor values are changing)
            \end{itemize}
            \item State neurons
            \item Transformer
            \item KF (Grandmother neuron)
            \item PF (Grandmother neuron)
            \item Language
        \end{itemize}
    
    
    \section{Neural circuits}
        \begin{itemize}
            \item Diverging neural circuit(To simulate time)
            \item Converging neural circuit(To simulate hierarchy of concepts such as corner is a part of the corridor)
        
        
        \end{itemize}
        
        When both spatially and temporally enough evidences are accumlated then a spike is fired and during the refractoring period another spike is not possible to be released. Each spike releases the same evidance to all connecting state neurons at next level or time slot. the evidences move from bottom (smallest classes) to topest (biggest class) and from left to right as time goes on.
