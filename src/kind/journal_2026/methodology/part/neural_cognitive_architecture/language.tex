    Language come from noun/verb couples and we consider consonom/vowel also as a noun/verb architecture.
    
    For the sake of simplicity we take for languages part a neuron but this is not the real case and for each word in human brain a circuit will be activated.
    
    By language we mean Ferdinand de Saussure theory on language that states language is formed of the flowing components.
    \begin{itemize}
        \item \textbf{Syntagmatic axis:} language elements combine in a linear sequence, for example words forming a sentence.
        \item \textbf{Paradigmatic axis:} language elements can replace each other in the same position, changing the meaning or value of the expression.
    \end{itemize}
    
    
    \begin{itemize}
        \item each language component such as words etc are grandmother neurons themselves
    \end{itemize}
