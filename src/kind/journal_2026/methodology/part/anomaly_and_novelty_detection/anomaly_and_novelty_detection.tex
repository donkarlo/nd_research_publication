   \section{}
      The main question that the agent tries to answer here is whether it can reconstruct what has happened to it using its existing language components or whether it is time to introduce a new component (phoneme, word, etc.).

      The goal of this section is to detect novelty in noisy data and build new language components from it. The inputs to the language model used during online learning are described in the following sections.




   \section{Discrepancy detection}
            \paragraph{Discussed forms of discrepancies in this research}
   \section{Anomaly:} An anomaly is an observation that violates an expected pattern or regularity. Anomaly is the difference between the agent's prediction of an evidence value that it expects to observe and the best estimate it can infer from the current evidence observation. Evidence is either provided by a sensory observation or inferred from neuronal activity.

            \paragraph{Application in this research:} It is used in Section \ref{autonomous_navigation} for surprise reduction through an active-inference formulation.

   \section{Novelty:}
      \seeherefooter{/nd_robotic_ai_learning_project/src/robot/part/mind/cognition/part/object_level/process/part/perception/novelty_detection/novelty_detection.tex}
      A persistent prediction error that exhibits reproducible temporal structure, while remaining compatible with the organism's viability constraints, provides evidence that the current generative model is incomplete rather than that the observations are merely noise. Such persistent structured errors can therefore drive structure learning or state-space expansion.
      
      Additionally, novelty is an episode that is not sufficiently represented by the organism's existing model or memory. Novelty is the continuous persistence of neural responses in populations of neurons.
      
      The type of novelty addressed in this research is described in \cite{smith-2020-an-active-inference-approach-to-modeling-structure-learning} as ``structure learning through state-space expansion``. This means that, when novelty is detected, a new state neuron should be added at the necessary level to improve the model's predictions.

      Biologically, new neurons are not added to learn new phenomena; instead, a new circuit is formed in the brain. However, this circuit formation is beyond the scope of this research.

      
      

            \paragraph{Application in this research:} It is used to update the generative model (a model that can generate sensory observations from hidden states of the world). This causes state-space expansion by adding new clusters at different levels of the neural-circuit model introduced in Section \ref{neural_cognitive_architecture}.
      






               In all phases, a statistical distribution is assigned to the state space. In this research, the directed Gaussian Wasserstein distance \cite{dowson-1982-the-frechet-distance-between-multivariate-normal-distributions} or \seeherefooter{/nd_math_learning_project/src/probability/distribution/discrepency/kind/distance/kind/wasserstein/gaussian/gaussian.tex} is used to measure the statistical distance between the estimated current state and the predicted state.



               The term \emph{directed} refers to assigning a direction to the scalar Wasserstein distance using the displacement between the two distribution means.
               Given the mean difference $\mathbf{d}=\boldsymbol{\mu}_1-\boldsymbol{\mu}_2$, its normalized direction is $\hat{\mathbf{d}}=\mathbf{d}/|\mathbf{d}|_2$.
               The directed Wasserstein vector is therefore defined as $\mathbf{v}_W=W_2(P,Q)\hat{\mathbf{d}}$, whose magnitude equals the Wasserstein distance while its direction follows the mean displacement.




      \subsection{Reason to use Wasserstein distance}
         \begin{itemize}
            \item When the two distributions are points (their covariance matrices are very close to 0), the Wasserstein distance gives a value very close to the Euclidean distance.
            \item When one is a distribution and the other is a point, it still produces a value.
            \item It is a metric, so unlike the Kullback--Leibler divergence, distance(A,B) = distance(B,A).
         \end{itemize}
         \[
         P_1
         =
         \mathcal{N}
         \left(
         \mu_1,
         \Sigma_1
         \right)
         \qquad
         P_2
         =
         \mathcal{N}
         \left(
         \mu_2,
         \Sigma_2
         \right)
         \]

         \[
         W_2^2
         \left(
         P_1,
         P_2
         \right)
         =
         \sqrt{
         \left\lVert
         \mu_1 - \mu_2
         \right\rVert_2^2
         +
         \operatorname{Tr}
         \left(
         \Sigma_1
         +
         \Sigma_2
         -
         2
         \left(
         \Sigma_2^{1/2}
         \Sigma_1
         \Sigma_2^{1/2}
         \right)^{1/2}
         \right)}
         \]


      \subsection{Interpretation}
         If the two Gaussian distributions are considered as two piles of mass, the distance represents how much effort it takes to move one pile to the other.

         \item Transformer (grandmother neuron for time-wise prediction). There is a trained Transformer for each state level.
         \item Kalman filter (grandmother neuron, diverging neural circuit that propagates along the time axis at all abstraction levels). The Kalman filter works with the intensity-change neuron.
         \item Particle filter (grandmother neuron, converging neural circuit that propagates upward along the abstraction-hierarchy axis). The particle filter works with the intensity-change sensory neuron.

      \end{itemize}
