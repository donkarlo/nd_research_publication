    This paper proposes a framework for novelty detection by forming a language from sensory electrical pulses to phoenems up to words and sentences and so on from the sensory data accumelated from an experience.
    
    By language we mean Ferdinand de Saussure theory on language that states language is formed of the flowing components.
    \begin{itemize}
        \item \textbf{Syntagmatic axis:} language elements combine in a linear sequence, for example words forming a sentence.
        \item \textbf{Paradigmatic axis:} language elements can replace each other in the same position, changing the meaning or value of the expression.
    \end{itemize}
