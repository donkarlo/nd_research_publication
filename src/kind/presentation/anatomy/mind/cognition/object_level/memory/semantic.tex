\begin{frame}[allowframebreaks]{Semantic memory, homeostasis}
    This is where the brain derives concepts such as different goals and actions.
    
    It includes concepts from which new instances can be derived, like a blueprint or map.
    \begin{itemize}
        \item \textbf{Goal}: something whose parameters (set-points) should be achieved
        \item \textbf{Action}: something that generates control signals to achieve the goal
        \item \textbf{Plan}: something that couples a set of goals with appropriate actions
    \end{itemize}

\end{frame}
