\begin{frame}[allowframebreaks]{Trace}
    A trace (called a \alert{feature structure} in linguistics) is an attribute--value description of a linguistic object, recursively built from features and processed through unification \cite{kay-1984-functional-unification-grammar}.
    
    
    \begin{itemize}
        \item In practice, it is an attribute--value structure, such as GPS:
            {longitude: 2, latitude: 4.1, altitude:1.2}
        \item \textbf{Trace} is the term used hereafter because it is shorter; it was adopted before I learned that ``feature structure'' is also a linguistic term similar to attribute--value structures in computer science.
    \end{itemize}

\end{frame}
