\begin{frame}[allowframebreaks]{Code structure}
    This has been done to make the system extensible.
    \begin{itemize}
        \item Dynamic composition for each robot
        \item Similar to ROS, an observer pattern
        \item ROS message conversion
        \item Storage and memory as decorator
        \item Inheritance in neurons
        \item PoseQuaternion in Physics and Math
        \item ROS mapper
        \item Mental action feedback (i.e. sensor modality segregation, clustering)
        \item Decoupling packages (RoboticAI, Datascience, Math, Physics)
        \item Decoupling architecture,  learning parameters
        \item Data pipes and filters
    
    \end{itemize}
\end{frame}
