\begin{frame}[allowframebreaks]{Dorsal and ventral attention network mode}
    Two large-scale brain networks require attention, unlike the default mode network.
    \begin{itemize}
        \item Ventral network mode (activates for a new observation or discrepancy) \cite{scalf-2014-trial-history-effects-in-the-ventral-attentional-network}
        \item Dorsal network mode (activates when the brain tries to follow a goal, such as a spatial goal) \cite{vossel-2014-dorsal-and-ventral-attention-systems, corbetta-2002-control-of-goal-directed-and-stimulus-driven-attention-in-the-brain}
    \end{itemize}
\end{frame}
